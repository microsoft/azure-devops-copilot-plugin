# Contributing

Thank you for your interest in the Azure DevOps extension for the GitHub Copilot App.

We are not accepting code contributions or pull requests at this time. To share feedback, report a problem, or suggest an improvement, [open a GitHub issue](https://github.com/github/app/issues/new?title=%5BAzureDevOpsExtension%5D).

Please do not include credentials, confidential information, or other sensitive data in the issue.
